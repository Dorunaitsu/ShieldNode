# ShieldNode — Agent Skill

An AI agent skill that helps developers integrate APIs through [ShieldNode](https://shieldnode.app), a secure API proxy gateway.

This skill teaches your AI agent (Claude Code, Cursor, Continue, custom agents...) how to:

- Configure a service in ShieldNode (base URL, auth method, credentials)
- Generate per-service reference documents from API docs
- Call the proxy correctly (handling base URL formatting pitfalls)
- Diagnose common errors (`401`, `404`, `429`, `502`...)

## Install

### Option 1 — Drop into your project

```bash
mkdir -p skills && curl -sL https://github.com/RP0-undefined/shieldnode-skill/archive/refs/heads/main.tar.gz \
  | tar -xz -C skills --strip-components=1
```

You end up with `skills/SKILL.md` and `skills/services/` in your project. Most agent runtimes (Claude Code, Cursor) auto-discover skills under a `skills/` directory.

### Option 2 — Single file

If you only want the instructions (no auto-discovery), grab the raw markdown:

```bash
curl -O https://raw.githubusercontent.com/RP0-undefined/shieldnode-skill/main/SKILL.md
```

Then point your agent at it manually (system prompt, custom instructions, etc.).

### Option 3 — Git submodule

```bash
git submodule add https://github.com/RP0-undefined/shieldnode-skill skills/shieldnode
```

## Usage

Once installed, just talk to your agent normally:

> *"I want to integrate the Stripe API through ShieldNode. Can you set it up?"*

The agent reads `SKILL.md`, walks you through service configuration, and generates a reference document under `skills/services/stripe.md` so future agent sessions don't have to re-fetch the Stripe docs.

## What's inside

| File                       | Purpose                                                                 |
|----------------------------|-------------------------------------------------------------------------|
| `SKILL.md`                 | The skill itself — read by the agent                                    |
| `services/`                | Per-service reference docs generated by the agent (one `.md` per API)   |
| `services/.gitkeep`        | Keeps the folder in git when empty                                      |

## About ShieldNode

[ShieldNode](https://shieldnode.app) is a secure API proxy gateway that lets you share API access with anyone — teammates, clients, AI agents, freelancers — without ever exposing your real credentials.

Instead of handing out your real OpenAI / Stripe / Resend / *(any HTTP API)* key, you create a **virtual key** in ShieldNode. The virtual key routes through the proxy to the real API. You can revoke it in under a second, cap it with rate limits or spending budgets, restrict it to specific endpoints, and see every request it made — without ever rotating your underlying credentials.

It works with virtually any HTTP API:

- **AI** — OpenAI, Anthropic, Mistral, Cohere, Replicate
- **Payments** — Stripe, Paddle, Lemon Squeezy
- **Comms** — Resend, Mailgun, Twilio, SendGrid
- **Data** — Airtable, Supabase, GitHub, Shopify
- Or any custom REST API you control

Real credentials are encrypted at rest and never exposed to clients. Virtual keys are hashed; only the user who created them ever sees the plaintext, and only once.

→ Read more at **[shieldnode.app/docs](https://shieldnode.app/docs)**
→ Try it free at **[shieldnode.app](https://shieldnode.app)**

## Why this skill

Most AI agents — even capable ones like Claude Code, Cursor, and Continue — don't natively know about ShieldNode. When you ask them to integrate an API, they default to embedding your real key directly in the code.

This skill flips that. With it installed, the agent:

1. Recognises ShieldNode as a routing target.
2. Knows how to configure a service correctly the first time (the base URL formatting trap is the single biggest source of `404`s and the skill bakes the rule in).
3. Writes a per-service reference document the first time it encounters a new API, so the next session doesn't pay the doc-reading cost again.
4. Diagnoses errors by HTTP code instead of guessing.

The result is fewer round-trips with the human, fewer leaked credentials, and integrations that work on the first try more often.
