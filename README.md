# ShieldNode — Agent Skill

An AI agent skill that helps developers integrate APIs through [ShieldNode](https://shieldnode.app), a secure API proxy gateway.

This skill teaches your AI agent (Claude Code, Cursor, Continue, custom agents...) how to:

- Configure a service in ShieldNode (base URL, auth method, credentials)
- Generate per-service reference documents from API docs
- Call the proxy correctly (handling base URL formatting pitfalls)
- Diagnose common errors (`401`, `404`, `429`, `502`...)

## Install

### Option 1 — Drop into your project

```bash
mkdir -p skills && curl -sL https://github.com/RP0-undefined/shieldnode-skill/archive/refs/heads/main.tar.gz \
  | tar -xz -C skills --strip-components=1
```

You end up with `skills/SKILL.md` and `skills/services/` in your project. Most agent runtimes (Claude Code, Cursor) auto-discover skills under a `skills/` directory.

### Option 2 — Single file

If you only want the instructions (no auto-discovery), grab the raw markdown:

```bash
curl -O https://raw.githubusercontent.com/RP0-undefined/shieldnode-skill/main/SKILL.md
```

Then point your agent at it manually (system prompt, custom instructions, etc.).

### Option 3 — Git submodule

```bash
git submodule add https://github.com/RP0-undefined/shieldnode-skill skills/shieldnode
```

## Usage

Once installed, just talk to your agent normally:

> *"I want to integrate the Stripe API through ShieldNode. Can you set it up?"*

The agent reads `SKILL.md`, walks you through service configuration, and generates a reference document under `skills/services/stripe.md` so future agent sessions don't have to re-fetch the Stripe docs.

## What's inside

| File                       | Purpose                                                                 |
|----------------------------|-------------------------------------------------------------------------|
| `SKILL.md`                 | The skill itself — read by the agent                                    |
| `services/`                | Per-service reference docs generated by the agent (one `.md` per API)   |
| `services/.gitkeep`        | Keeps the folder in git when empty                                      |
